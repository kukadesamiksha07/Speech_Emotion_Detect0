ABOUT THE EXPERIENCE

Emotion, explored through sound.

VoxAura is a speech emotion recognition demo. It uses audio features and a trained machine-learning model to estimate an emotion from a voice sample.

It does not know a person's true inner state, and predictions can be wrong. Use it as an educational experiment—not as a diagnostic tool.
