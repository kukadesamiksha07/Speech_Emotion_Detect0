# VoxAura AI — Speech Emotion Recognition

A dark, cinematic voice assistant interface for a Speech Emotion Recognition ML project.

## Folder structure

```text
VoxAura_Speech_Emotion_AI/
├── app.py
├── speech_emotion_model.pkl   # Copy your trained model here
├── requirements.txt
├── templates/
│   └── index.html
└── static/
    ├── style.css
    └── app.js
```

## Setup

1. Copy the `speech_emotion_model.pkl` generated by your training script into this folder, beside `app.py`.
2. Open a terminal in this folder.
3. Create and activate a virtual environment if you want to keep dependencies separate.
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the app:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

Microphone access is normally allowed on localhost. On a deployed website, use HTTPS.

## Important compatibility note

The feature extraction in `app.py` must exactly match the feature extraction used when you trained `speech_emotion_model.pkl`. This version matches the MFCC (40), chroma, mel (64), zero-crossing-rate, and spectral-centroid feature order from the companion training example.

The model's `predict_proba` output is a model score, not a calibrated measure of a person's true emotional state. The app is for educational experimentation and should not be used to diagnose or judge people.
